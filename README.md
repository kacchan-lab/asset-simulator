# 資産形成シミュレーター

ブラウザだけで動く、日本語の資産形成シミュレーターです。PC・スマートフォンに対応しています。外部API、ログイン、追加ライブラリは使用しません。

## 起動方法

一番簡単な方法は、ダウンロードしたフォルダの **index.html をダブルクリック**してブラウザで開くことです。依存関係のインストールやビルドは不要です。

ローカルサーバーを使う場合は、このフォルダで次を実行します（Python 3が必要です）。

```sh
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。終了はターミナルで `Ctrl+C` を押します。

## 使い方

1. 「現在の投資資産」「毎月の積立額」「年2回のボーナス投資額（1回あたり）」「想定年利」「目標金額」を入力します。金額の単位は円です。
2. 入力すると自動で再計算します。「目標までの道のりを計算」ボタンでも計算できます。
3. 目標までの年数・月数、到達予定年月、資産総額、運用益を確認します。グラフには資産総額、投資元本、目標金額を表示します。

初期値は現在100万円、毎月3万円、ボーナス1回10万円、年利5%、目標1,000万円です。入力は保存・送信されず、再読み込みすると初期値に戻ります。

## 計算ルール

- 開始月はブラウザの現在年月です。
- 月利 = 想定年利 ÷ 100 ÷ 12。年利は0〜100%に対応します。
- 毎月末の資産 = 前月の資産 × (1 + 月利) + 毎月の積立額 + 該当月のボーナス。
- ボーナスは開始から6か月ごとに投資します（6・12・18か月目…）。特定の暦月には固定していません。
- 計算途中では丸めず、金額表示を円単位に丸めます。
- 現在の資産が目標以上なら「すでに目標達成」と表示します。
- 最大100年（1,200か月）まで計算し、未到達ならその旨を表示します。
- 税金、手数料、インフレ、利率の変動は考慮しません。将来の運用成果を保証するものではありません。

## テスト

Node.js 18以上があれば、追加パッケージなしで実行できます。

```sh
node --test tests/simulator.test.js
```

年利0%、ボーナス、月次複利、達成済み、運用益のみでの達成、未到達、不正入力、年月の繰り上がりを確認します。

## 動作確認結果

- 計算の自動テスト：8件すべて成功。
- ChromiumでHTTPサーバー経由の画面起動、自動再計算、計算ボタン、達成済み・未到達、不正入力時の表示、SVGグラフを確認。
- 画面幅1,280px・390px・320pxで横方向のはみ出しがないことを確認。JavaScriptエラーなし。
- このクラウド環境のChromiumはファイルURLを制限しているため、`index.html` の直接起動は実機ブラウザで未検証です。検証済みの起動方法は上記のPython HTTPサーバーです。

## クラウド環境でのWebプレビューについて

クラウド内で起動したサーバーの `localhost:8000` は、自分のPCのChromeから直接開けません。Chromeの `localhost` は自分のPCを指すためです。

クラウドのプレビュー機能がポート公開に対応している場合は、次のコマンドで起動し、ポート8000を公開して得られるプレビューURLを使用します。

```sh
python3 -m http.server 8000 --bind 0.0.0.0 --directory /workspace/asset-simulator
```

このオンボーディング画面にはプレビューURLを発行する機能が提供されていないため、サーバーが起動していてもPCの `localhost:8000` では確認できません。手元で簡単に見るには、フォルダ全体をダウンロードして `index.html` をChromeで開いてください。HTML・CSS・JavaScriptの4ファイルを同じフォルダに置きます。
